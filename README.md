# 💻 PPSC Lab Programs (C Language)

This repository contains all my C programs implemented as part of the **PPSC (Programming for Problem Solving)** lab curriculum! 🚀

## 📂 Topics Covered
* **⚡ Basics & Control Statements:** Arithmetic operations, conditions (`if-else`), loops, and switch cases.
* **🔄 Functions & Recursion:** Factorials, Fibonacci series, GCD, and parameter passing.
* **📊 Arrays & Matrices:** 1D and 2D arrays, matrix multiplication, sorting (Bubble Sort), and searching.
* **🔤 Strings:** String manipulation and character counting without built-in functions.
* **🧠 Pointers & Memory Allocation:** Dynamic memory allocation using `malloc` and `calloc`.
* **📁 File Handling:** Reading, writing, and appending data to text files.

## 🛠️ Tech Stack
* **Language:** C 💻
